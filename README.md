# 刘令文 · Academic 主页

基于原主页的内容与资源制作。版式参考 [Yann Dubois 的主页](https://yanndubs.github.io/)：顶部导航、左侧圆形头像与联系入口、右侧正文、白底灰字与酒红色链接。

## 打开与部署

直接用浏览器打开 `index.html`，无需安装依赖或构建。可选本地预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

随后访问 http://127.0.0.1:8765/ 。

本目录是静态网站，保留 `assets/` 层级即可通过 GitHub Pages 发布，已包含 `.nojekyll`。公开主页地址为 [llw-wu.github.io](https://llw-wu.github.io/)，源代码仓库为 [LLW-WU/llw-wu.github.io](https://github.com/LLW-WU/llw-wu.github.io)。更新只替换网站文件，不需要删除仓库或更改访问地址。

## 页面与内容

- 首页：个人介绍，以及“学术科研、数据分析、商业模型”三栏入口（圆形薄荷绿图标、简短说明和详情按钮）。
- 学术科研：8 个公开项目统一平铺，不按院校分组；其下展示 8 篇公开论文，不再设单独的论文页面或顶部导航入口。论文列表不显示年份，完整年份仍保存在内容数据中；项目引用可跳转到对应论文。
- 数据分析：已删除三条 BCGX 写作提示及底部重复参考文献，页面不显示院校标题和空白段落；9 个案例正文保留原有文字与格式，英文模式仍使用中文原稿。
- 商业设计：沿用原来的“内容整理中”。
- 教育经历：原内容中的 3 所学校及时间显示在公共左侧栏，不再设独立页面或顶部导航入口。

科研项目、数据案例和论文条目均采用淡蓝色左侧竖线与统一留白。

`content.js` 在原版基础上删除了三条 BCGX 写作提示及数据页八段重复参考文献；独立的完整论文数据仍保留，隐藏项目和论文继续隐藏。未新增研究结论、经历或成果。首页对介绍做了轻微衔接排版，完整研究文案仍在科研页。桌面、平板和手机使用不同布局，导航与语言切换支持键盘操作。

## 维护

- 内容：`content.js`
- 版式：`index.html`、`style.css`
- 页面与交互：`app.js`、`site-core.js`
- 头像：`selfphoto.jpg`
- 图片与来源：`assets/`，图源记录在 `assets/models/sources.json`
- 本地编辑器：`edit.html`、`editor.js`、`editor.css`

从页面底部进入“编辑内容”可保存浏览器本地草稿、预览并导出 `content.js`。导出的文件需要手动替换本目录中的同名文件；浏览器草稿不会自动改动公开页面。新版草稿使用独立存储键，与原版隔离。

修改主页 HTML、CSS 或 JS 后，请同步生成编辑器内嵌预览：

```sh
python3 scripts/build_preview.py
```

页面不依赖在线字体、第三方脚本或构建服务；邮件、Scholar、GitHub 和论文链接需联网访问。
