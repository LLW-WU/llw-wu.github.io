# LIU Lingwen · 简约中英双语个人主页

这是**同一个主页**，不是中英文两个相互独立的网站。沿用之前的简约个人主页：姓名、个人简介、技术研究 / 数据科学 / 商业设计三个栏目，以及折叠展示的项目说明与论文列表。

## 先打开看看

- **`index.html`**：个人主页。右上角点击 **中文 / EN**，整个网页会切换语言，同时保留当前方向栏目。
- **`edit.html`**：可视化文字编辑页。可以单独编辑中文、英文，还可以添加、删除项目与论文。

在 Chrome 等桌面浏览器里可以直接双击 HTML 文件预览。如果本地安全策略限制 JavaScript 加载，请在该文件夹运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。

## 最简单的修改方式

1. 打开 **`edit.html`**。
2. 选顶部 **中文** 或 **English**（这是「正在编辑的内容语言」，不是浏览器界面的翻译按钮）。
3. 选择「个人简介 / 技术研究 / 数据科学 / 商业设计 / 论文列表」。
4. 填写简介、Key Concept、流程和项目内容。每个项目可以独立展开；可以新增、删除、调整顺序。
5. 点击底部 **下载 content.js**；将下载文件替换 GitHub Pages 仓库里的同名文件，提交后线上网页才更新。

**注意：编辑器不会直接修改线上网站**。浏览器内的草稿可能在清缓存后消失，所以修改完成后建议及时导出文件备份。

同一项目的中英文属于一条共同的项目记录，**新增 / 删除 / 调整顺序会同时影响两种语言**；项目网页链接、邮箱、照片文件名、论文作者与官方刊物名也是两种语言共用的。其余可翻译的内容在中英文模式下分别填写。

如果你上一版用编辑器写过很多文字，先在新版编辑器中点击「**导入以前的 content.js**」，选择旧文件；编辑器会保留英文内容并尽可能保留现有译文。对旧文件里新增或自行修改的部分，建议随后检查中文版是否需要补充。导入过程不会执行上传的 JavaScript，只读取其中的 JSON 数据。

## 文件说明

| 文件 | 用途 | 是否需要经常改 |
|---|---|---|
| `index.html` | 对外的简约个人主页 | 不用 |
| `style.css` | 样式与手机端布局 | 通常不用 |
| `app.js` | 切换语言、显示栏目和论文 | 不用 |
| `content.js` | **中英文全部文字与项目数据** | 通过编辑器导出替换 |
| `edit.html` | 可视化编辑界面 | 不用 |
| `editor.js` | 编辑、草稿、导出与导入功能 | 不用 |

## GitHub Pages 部署

将以上六个文件放到 **`llw-wu.github.io` 仓库根目录**，替换旧版同名文件后提交即可。原来的 `selfphoto.jpg` 可以继续放在根目录；若没有照片，默认显示“LL”占位符。**不要删除旧的照片文件**。

编辑器可以上传仓库，也可以仅保存在自己电脑里：即使在线访问 `edit.html`，它也没有 GitHub 写入权限，不会替任何访客直接修改线上内容。

- 中文技术研究：`https://llw-wu.github.io/?lang=zh#research`

上面这些网址是**部署后的预期地址**，不是已经替你发布的网站。首次进入默认中文；点过语言按钮后，会尽量记住本浏览器的语言偏好。链接中 `?lang=...` 的显式设置优先。
